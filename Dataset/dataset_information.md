# Dataset Information

## Study

**Title:** Integration of genome-wide analysis to characterize long noncoding RNAs in diverse immune cell types of the stage IV melanoma patients

## Organism

Homo sapiens

## Sequencing Platform

Illumina HiSeq 2000

## Sequencing Design

Paired-end RNA sequencing

## Reference Genome

GRCh38

## Data Source

NCBI Gene Expression Omnibus (GEO)

## GEO Accession

GSM2807115

## Library Preparation

RNA was prepared using the Qiagen miRNeasy Kit. RNA samples with
integrity values of ≥6.0 were processed into TruSeq libraries.

Libraries were sequenced as 51 × 2 paired-end reads on an Illumina
HiSeq 2000.

## Analysis Design

The project used RNA-Seq data for transcriptomic analysis, including:

- Quality control
- Read trimming
- Reference genome alignment
- SAM/BAM processing
- Gene-level read quantification
- Differential expression analysis
- Functional and pathway analysis

## Reference and Annotation

Reference genome: GRCh38

Gene annotation: GTF annotation corresponding to the reference genome
used for the analysis.

## Note on Raw Data

Raw FASTQ files and large alignment/reference files are not included
in this GitHub repository because of their large file size.

The repository documents the analysis workflow, commands, scripts,
results and biological interpretation.
